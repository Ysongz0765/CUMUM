# 时间对齐说明

内部 canonical 网格按自然日 `slot=1..144` 定义，每个区间为 `[00:00,00:10)` 至 `[23:50,次日00:00)`，区间末端为 `timestamp_end`。原始标签 `0:00+1` 表示次日零点，不能当作当天起点。结果模板展示从 `0:10-0:20` 开始，属于循环展示顺序；模型内部不移动。附件 3 日期字段采用有效日期向前填充，非日期值（包括 Excel 显示的 `28`）不解析；每个 issue 的 horizon 仍是小时功率预测，未除以 6。小时预测插值到10分钟时，发布后首小时缺少左端预测锚点，采用已发布的“预报1小时”值向前保持到发布后10分钟，不引入真实PV或后续发布信息；之后在同一次发布的相邻小时预测点之间线性插值。该接口仅为问题三准备，问题二不调用。
